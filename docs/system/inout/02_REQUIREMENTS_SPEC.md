# 02. 요구사항 명세서 - 입출고 관리 (InOut)

문서 버전: 1.0.0 | 생성일: 2026-01-12

---

## 1. 입고 요구사항

- REQ-IN-001: 입고 목록 조회 - 검색, 필터, 페이징
- REQ-IN-002: 입고 등록 - 발주서 기반 또는 직접 입력
- REQ-IN-003: 입고 상세 - 입고 정보 확인 및 수정

---

## 2. 출고 요구사항

- REQ-OUT-001: 출고 목록 조회 - 검색, 필터, 페이징
- REQ-OUT-002: 출고 등록 - 주문 기반 출고 처리
- REQ-OUT-003: 출고 상세 - 출고 정보 확인
