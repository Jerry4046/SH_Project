# 01. 시스템 구상도 - 입출고 관리 (InOut)

문서 버전: 1.0.0 | 생성일: 2026-01-12

---

## 1. 시스템 개요

- 제품의 입고/출고 전 과정을 체계적으로 관리
- 주문 접수부터 송장 발행까지 자동화
- 선발주/정상주문 간 이중출고 방지
- 모든 이력 추적 및 로그 관리

---

## 2. 입고 프로세스

- 발주서(이카운트/직접) → 입고등록 → 상태결정 → 재고반영
- 상태: 정상입고, 부분입고, 반품

---

## 3. 출고 프로세스

- 주문 → 검토단계 → 출고선택 → 재고차감
- 검토: 재고확인, 주문검증, 출고여부 선택
- 창고: 본창고(sh_qty), 거래처창고(hp_qty)
