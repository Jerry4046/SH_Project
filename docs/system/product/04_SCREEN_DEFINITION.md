# 04. 화면 정의서 - 제품 관리 (Product)

문서 버전: 1.1.0 | 생성일: 2026-01-12

---

## 목적

- 제품(Product) 모듈의 화면 구성과 주요 UI 요소를 정의합니다.

---

## 1. 제품 목록 화면 (SCR-PRD-001)

- 경로: /inventory
- 구성요소:
  - 필터: 유형, 카테고리, 검색어
  - 테이블: 제품코드, 제품명, 규격, 입수량, 재고상태, 등록일
  - 재고상태 뱃지: 정상(초록), 부족(노랑), 없음(빨강)
  - 버튼: [제품등록], [선택삭제]
- 기능: 조회, 페이징, 정렬, 체크박스 선택

---

## 2. 제품 등록 화면 (SCR-PRD-002)

- 경로: /product/register
- 구성요소:
  - 코드 조합: 회사코드, 유형코드, 카테고리코드, 아이템코드
  - 기본 정보: 제품명, 규격, 입수량, 최소재고
  - 변형 테이블: 입수량별 BOX/낱개 수량
  - 이미지 업로드 영역
  - 버튼: [등록], [취소]
- 기능: 코드 자동 생성, 변형 추가/삭제, 이미지 미리보기

---

## 3. 제품 상세 화면 (SCR-PRD-003)

- 경로: /product/detail/{id}
- 구성요소:
  - 기본 정보 표시
  - 변형 목록 테이블
  - 이미지 갤러리
  - 재고 현황
  - 버튼: [수정], [비활성화], [목록]
- 기능: 상세 조회, 수정 모드 전환

---

## 4. 제품 수정 화면 (SCR-PRD-004)

- 경로: /product/detail/{id} (수정 모드)
- 구성요소:
  - 수정 가능 필드
  - 수정 사유 입력 (필수)
  - 버튼: [저장], [취소]
- 기능: 수정 저장, 이력 기록
