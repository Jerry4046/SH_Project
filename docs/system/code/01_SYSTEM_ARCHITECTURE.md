# 코드 관리 시스템 구상도

문서 버전: 1.0.0 | 생성일: 2026-01-12

---

## 1. 시스템 개요
- 시스템 전반에서 사용되는 코드 그룹 및 공통 코드 관리
- 유연한 코드 체계로 확장성 확보
- 관리자 전용 기능

---

## 2. 코드 체계
- PD_CP: 제품 회사코드
- PD_TY: 제품 유형코드
- PD_CT: 제품 카테고리코드
- FC_CODE: 생산공장코드
- IN_STATUS/OUT_STATUS: 입출고 상태
- ORD_TYPE/ORD_STATUS: 주문 종류/상태
- DLV_COMPANY: 택배사
