# 02. 요구사항 명세서 - 주문 관리 (Order)

문서 버전: 1.1.0 | 생성일: 2026-01-21

---

## 목적

- 주문(Order) 모듈의 요구사항(REQ)을 기능 단위로 빠짐없이 정리합니다.

---

## 범위 (In / Out)

- **In**: 주문 조회, 일반접수, 파일접수, 자동 매칭, 송장 생성
- **Out**: 결제/정산, 택배사 API 실시간 연동

---

## 용어(정의)

- **REQ-ORD-\***: 주문 모듈 요구사항 ID

---

## 기능 요구사항

### REQ-ORD-001: 주문 목록 조회

- 날짜/거래처/제품/상태 필터 조회
- 페이징, 정렬

### REQ-ORD-002: 일반접수(단건 주문 등록)

- 거래처, 제품, 수량, 주소, 메모 입력
- 저장 시 order_tb INSERT

### REQ-ORD-003: 파일접수(엑셀 업로드)

- 엑셀 파일 업로드 → 파싱 → 화면 표시
- 인라인 수정 후 확정 저장

### REQ-ORD-004: 선발주 자동 매칭

- 파일접수 주문과 선발주를 대리점명+제품명 기준 매칭
- 수량 차감/잔량 이월 처리

### REQ-ORD-005: 송장 생성

- 택배사별 양식(로젠/롯데) 출력
- 메모에 CJ/롯데 포함 시 롯데, 그 외 로젠

---

## 데이터 항목(핵심)

- order_tb, order_item_tb, pre_order_tb, courier_fare_tb

---

## 비기능 요구사항

- 업로드 오류 시: 사용자에게 오류 목록 제공
- 대량 업로드 성능 고려(파일 사이즈 제한 등)

---

## 예외/에러 케이스

- 엑셀 필수 컬럼 누락, 형식 불일치
- 매칭 키 불일치로 미매칭 발생
- 송장 출력 대상 데이터 누락

---

## 관련 화면/테이블/코드 링크

- 화면: /order, /order/register, /order/upload, /order/invoice
- 테이블: order_tb, order_item_tb, pre_order_tb, courier_fare_tb
- 코드: OrderService(매칭 로직), Excel parser
