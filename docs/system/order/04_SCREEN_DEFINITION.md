# 04. 화면 정의서 - 주문 관리 (Order)

문서 버전: 1.1.0 | 생성일: 2026-01-21

---

## 목적

- 주문(Order) 모듈의 화면 구성과 주요 UI 요소를 정의합니다.

---

## 1. 주문 목록 화면 (SCR-ORD-001)

- 경로: /order
- 구성요소:
  - 필터: 날짜 범위, 거래처, 제품, 상태
  - 테이블: 주문번호, 거래처, 제품, 수량, 상태, 등록일
  - 버튼: [일반접수], [파일접수], [송장출력]
- 기능: 조회, 페이징, 정렬

---

## 2. 일반접수 화면 (SCR-ORD-002)

- 경로: /order/register (모달)
- 구성요소:
  - 입력: 거래처 선택, 제품 선택, 수량, 주소, 메모
  - 버튼: [등록], [취소]
- 기능: 단건 주문 등록

---

## 3. 파일접수 화면 (SCR-ORD-003)

- 경로: /order/upload
- 구성요소:
  - 파일 업로드 영역
  - 미리보기 테이블 (인라인 수정 가능)
  - 버튼: [업로드], [확정], [취소]
- 기능: 엑셀 업로드 → 파싱 → 수정 → 확정 저장

---

## 4. 송장 출력 화면 (SCR-ORD-004)

- 경로: /order/invoice
- 구성요소:
  - 대상 주문 목록
  - 택배사 선택 (자동/수동)
  - 버튼: [출력]
- 기능: 택배사별 송장 양식 생성
