# 캘린더 시스템 구상도

문서 버전: 1.0.0 | 생성일: 2026-01-13

---

## 1. 시스템 개요
- 업무 일정 관리 및 공유
- Google Calendar 연동을 통한 일정 표시
- 입출고, 발주, 배송 등 주요 업무 일정 관리

---

## 2. 현재 구현 상태
- Google Calendar 임베드: ✅ 구현됨 (iframe으로 공유 캘린더 표시)
- 일정 조회: ✅ 구현됨 (읽기 전용)
- 일정 등록/수정: ❌ 미구현 (Google Calendar에서 직접 관리)
- 시스템 연동: ❌ 미구현 (입출고/주문 일정 자동 등록)

---

## 3. 연동 방식
- 현재: iframe 임베드 방식 (구현 간단, 별도 인증 불필요)
- 향후: Google Calendar API 연동 검토 (일정 자동 등록)
