# 04. 화면 정의서 - 인증/사용자 (Auth)

문서 버전: 1.0.0 | 생성일: 2026-01-12

---

## 1. 로그인 화면 (SCR-AUTH-001)

- 경로: /login
- 구성요소: 아이디 입력란, 비밀번호 입력란, 로그인 버튼
- 에러 메시지: "아이디 또는 비밀번호가 잘못되었습니다."

---

## 2. 공통 헤더 (header.jsp)

- 메뉴: 재고관리 시스템, 제품, 매출, 송장, 단가맵, 거래처, 입/출고 관리, 코드등록*
- 사용자 정보: "사용자: {username}" 표시
- 버튼: 관리자-[회원관리], 일반-[권한없음], 전체-[로그아웃]
- * 코드등록은 관리자(A) 전용 메뉴

---

## 3. 회원가입 화면 (SCR-AUTH-002)

- 경로: /signup (관리자 전용)
- 구성요소: 아이디*, 이름*, 비밀번호*, 등급* (관리자/일반 라디오)
- 버튼: [등록]
