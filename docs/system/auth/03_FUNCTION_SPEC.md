# 03. 기능 명세서 - 인증/사용자 (Auth)

문서 버전: 1.0.0 | 생성일: 2026-01-12

---

## 1. 로그인 (FN-AUTH-001)

- 경로: GET /login, POST /login
- 처리: 아이디/비밀번호 입력 → Spring Security 인증 → BCrypt 검증 → 성공 시 세션 생성, /home 이동

---

## 2. 로그아웃 (FN-AUTH-002)

- 경로: GET /logout
- 처리: 세션 무효화 → /login 리다이렉트

---

## 3. 회원가입 (FN-AUTH-003)

- 경로: /signup
- 권한: 관리자(A) 전용
- 처리: 사용자 정보 입력 → 비밀번호 BCrypt 암호화 → account_tb 저장

---

## 4. 세션 정보 표시 (FN-AUTH-004)

- 위치: header.jsp
- 표시: 사용자명 (관리자는 "관리자" 표시)
- 관리자: 회원관리 버튼 / 일반: 권한없음 표시
- 로그아웃 버튼
